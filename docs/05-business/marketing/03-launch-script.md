# miTch 30-Second Launch Script

## Format

30 seconds, product launch video, voice-over first, visuals second.

## Script

**0-5s**  
Everyone keeps asking for identity data they do not actually need.

**5-10s**  
miTch changes that. It is the privacy firewall for identity proofs.

**10-18s**  
A verifier asks for age, role, status, or eligibility. miTch returns only the minimum proof required.

**18-24s**  
No raw data. No over-disclosure. No blind trust. Every decision stays auditable.

**24-30s**  
miTch. Be prove only what is needed.

## Visual beats

1. Request enters.
2. Policy gate evaluates.
3. Wallet reveals only the allowed claim.
4. Audit trail records the decision.
5. End on the claim: Be prove only what is needed.

## On-screen text

- Privacy firewall for identity proofs
- Selective disclosure
- Fail-closed policy
- Full audit trail
